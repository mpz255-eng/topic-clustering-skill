# 聚类算法选择参考

## 三种方法对比

| | KMeans | 层次聚类 | LDA |
|---|---|---|---|
| **原理** | 距离最小化，球形簇 | 自底向上合并最相似簇 | 概率生成模型，文档→主题→词 |
| **速度** | 快 | 慢（O(n²)） | 中等 |
| **适合数据量** | 任意 | < 500 篇 | > 100 篇，长文本更好 |
| **K 选择** | 肘部法（必须） | 树状图切割 | 主题数可按经验/困惑度 |
| **输出** | 硬分类 + 质心词 | 硬分类 + 树状图 | 软分类（概率分布）+ 主题词 |
| **可解释性** | 关键词直观 | 层级关系清晰 | 主题词有时语义模糊 |
| **中文适用** | 好 | 好 | 一般（短文本差） |

## 场景建议

- **新闻分类、评论归类** → KMeans（首选）
- **探索文档层级结构、子话题关系** → 层次聚类
- **长文本（论文、报告），需要软分类** → LDA

## 肘部法使用

- K 范围建议 3–20
- 理想拐点：SSE 下降速率明显减缓的位置
- 如果没有明显拐点，优先选择 8–12（实践中常见）

## 常见问题

**Q: 跑完聚类后关键词太泛？**
- 提高 max_df（过滤高频泛词）
- 降低 min_df（保留更多低频词）
- 检查停用词表是否完善

**Q: 某个簇太大（> 50%）？**
- 增大 K 值再跑一次
- 考虑对大数据集做二次聚类

**Q: 中文分词不准？**
- 提供自定义词典（领域术语、专有名词）
- 检查原始文本是否有编码问题
